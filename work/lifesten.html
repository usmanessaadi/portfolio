Rebuilding a health app's static screens into a real design system.

Converting Lifesten's pre-designed PDF screens into a production-grade Figma file, with a full token library and component set grounded in consistent spacing and type hierarchy.

Scope
Design system, component library
Role
Design Systems Designer
Client
Lifesten
Year
2026

Overview

Lifesten is a gamified health and wellness app combining habit tracking, community, medical record-keeping, and rewards in one product, helping users build healthier routines through streaks, community support, and a coach-like AI companion.

The product and visual design already existed, laid out screen by screen in a PDF. What was missing was a real design system underneath it. My job was to convert Lifesten's pre-designed PDF screens into a production-grade Figma file, with a full token library and component set grounded in consistent spacing and type hierarchy.

The starting point

The PDF was thorough but flat: every screen fully designed, none of it systemized. No components, no tokens, no shared button or navigation patterns, no single source of truth for color, type, spacing, or corner radius.

Rebuilding it meant working backwards from the finished screens: pulling out the values actually in use, mapping them onto a consistent spacing and typography scale, then reconstructing each screen to pull from that system instead of hardcoded values.

Rebuilding across the core areas

The PDF organized Lifesten into distinct parts, each already designed, that needed their own logic in the component library while staying consistent with the rest.

Journeys & habits

Guided wellness programs for sleep, nutrition, mindfulness, and activity, with missions, streaks, milestones, and an AI coach chat.

Community & social

Challenges, leaderboards, and Health Circles, small private groups where friends or family track goals together.

Health records & sharing

A full health passport covering measurements, lab results, medications, and documents, plus a secure sharing flow for doctors and caregivers.

Marketplace

A points economy where earned rewards redeem for real perks, gym day passes, nutrition programs, and partner offers.

Approach

I started with the design system rather than the screens: color, type, spacing, and radius values pulled from the PDF and structured as Figma variables, then the core components every screen would reuse, buttons, navigation, cards, form fields. Only then did I move into rebuilding the screens section by section.

Each screen was rebuilt to match the original reference, then checked against the token system before moving to the next. Working in a file a collaborator was also actively editing meant keeping track of who was working where, and confirming nothing had been overwritten before building on top of it.

What shipped

The final Figma file covers seven core product areas, Journeys, Challenges, Community, Health Passport, Insights, Rewards & Marketplace, and Sharing, with more than 100 individual screens rebuilt from the original PDF on a shared token system.

Outcome

The file is complete and internally consistent, ready to hand to engineering. Every screen traces back to the same color, type, and spacing variables, and every button, card, and navigation pattern was built once and reused everywhere. The original design stays exactly as designed. Lifesten now has a real design system underneath it, instead of disconnected static screens.
